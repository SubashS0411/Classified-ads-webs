header & footer
ompt: Create NextGen Header and Footer
Please generate a responsive, modern Header and Footer for a web application using HTML5, Tailwind CSS, and Vanilla JavaScript. The design should be premium, with "Glassmorphism" effects, smooth animations, and full support for Dark Mode and RTL (Right-to-Left) layouts.

1. Global Requirements
Framework: Tailwind CSS (via CDN or standard config).
Icons: Lucide Icons (<script src="https://unpkg.com/lucide@latest"></script>).
Font: Inter and Outfit (Google Fonts).
State Persistence: Theme (Dark/Light) and Direction (LTR/RTL) must be saved in localStorage.
2. Header Specifications
The header should be a sticky navbar with the following features:

Styling:
Background: White (Light Mode) / Slate-950 (Dark Mode) with 90% opacity and backdrop-blur-xl.
Bottom Border: Slate-200 (Light) / Slate-800 (Dark).
Height: Fixed (e.g., h-20).
Logo Area:
A square icon box (Indigo-600 background, rounded corners) containing the letter "C".
Text: "ClassifiedPro" (Bold, with "Pro" in indigo color).
Hover Effect: Icon rotates slightly on hover.
Desktop Navigation (Hidden on Mobile):
"Home" Dropdown: Triggers on hover. Shows links for "Home V1" and "Home V2".
Standard Links: "About", "Services", "Contact".
"Dashboards" Dropdown: Triggers on hover. Shows links for "User Dashboard" and "Admin Control" with icons.
Action Buttons (Right Side):
RTL Toggle: Button with Globe icon. Toggles dir="rtl" on HTML tag.
Theme Toggle: Button with Moon/Sun icon. Toggles dark class on HTML tag.
Get Started: Primary Call-to-Action button (Indigo background, rounded).
Mobile Menu Toggle: Visible only on mobile (lg:hidden). Hamburger icon.
3. Mobile Navigation (Drawer)
Overlay: Black background with 60% opacity, fades in when menu opens.
Drawer:
Off-canvas sidebar (width 50% or full).
Slides in from Left in LTR mode, and from Right in RTL mode.
Contains vertical list of all links (Home, About, Services, Dashboards).
Close button (X icon) at the top.
4. Footer Specifications
Background: Dark gradient (footer-gradient class: linear-gradient(135deg, #1e293b, #0f172a)), animated if possible.
Layout: 4-Column Grid on Desktop, Stacked on Mobile.
Brand: Logo + Short description.
Quick Links: Home, About, Services, Contact.
Account: Dashboard links, Login, Terms.
Newsletter: Email input + "Go" button.
Bottom Bar: Copyright text and Social Media icons (Facebook, Twitter, Instagram).
Styling Details:
Text: Slate-300.
Headers: White, bold.
Links: Hover effect (color change + small indentation).
5. JavaScript Functionality
Include a script to handle:

Theme Toggle: Check localStorage or system preference on load. Toggle .dark class on click.
RTL Toggle: Check localStorage. Toggle dir="rtl" or dir="ltr" on <html>.
Mobile Menu:
Add/Remove -translate-x-full classes based on state.
Handle RTL specific logic (e.g., rtl:translate-x-full).
Close menu when clicking outside (overlay) or pressing Escape.
Dropdowns: Simple hover logic for desktop, click logic for mobile if needed.
6. CSS Extras (Custom)
Provide CSS for:

.footer-gradient: The dark animated background.
.glass-card: For transparency effects.
.brand-glow: Hover glow effect for the logo.
